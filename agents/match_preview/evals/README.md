# Evaly match_preview

Sem patří kontrolní případy (vstup + rubrika). Nápady na rubriku:

- Sekce 1 obsahuje buď kritické upozornění, nebo přehled ligy, nikdy obojí.
- Sekce 2 má přesně 3 odrážky a žádnou tabulku.
- Sekce 3 a 4 popisují přesně 5 zápasů.
- Metriky jsou interpretované, ne jen vyjmenované.
